# Bug Report — BUG-001

| Campo | Detalhes |
|---|---|
| **ID** | BUG-001 |
| **Título** | Campo senha aceita espaço em branco como caractere válido |
| **Severidade** | Média |
| **Prioridade** | Alta |
| **Status** | Aberto |
| **Ambiente** | Produção / Chrome 124 / Windows 11 |
| **Autor** | Giullia Fernandes |
| **Data** | Mai/2026 |

---

## Descrição
O campo de senha na tela de login aceita espaços em branco como 
caracteres válidos, permitindo que senhas como " " (apenas espaços) 
sejam cadastradas e utilizadas para autenticação.

---

## Passos para Reproduzir
1. Acessar a página de cadastro
2. Preencher os campos de nome e email
3. No campo "Senha", digitar apenas espaços (ex: "     ")
4. Confirmar senha com os mesmos espaços
5. Clicar em "Cadastrar"

---

## Resultado Esperado
Sistema deve exibir mensagem de validação:  
*"A senha não pode conter apenas espaços em branco."*

## Resultado Obtido
Cadastro realizado com sucesso usando senha composta apenas de espaços,
permitindo login posterior com essas credenciais.

---

## Impacto
Risco de segurança — usuários podem criar senhas fracas sem perceber,
comprometendo a segurança da conta.

---

> 📎 Captura de tela 2 — Cadastro concluído com sucesso
